ParkEasy - Parking Reservation App Development Prompt

App Overview

Create a comprehensive parking reservation mobile app similar to Uber's design philosophy, focused on the Indian market with ₹ INR pricing and bilingual support (English/Hindi).

TECHNICAL IMPLEMENTATION

Core Technology Requirements

Frontend: React Native (iOS + Android)
Backend: Node.js with Express/Django
Database: MongoDB/PostgreSQL
Real-time: Socket.io/Firebase
Maps: Google Maps API
Payments: Razorpay Gateway
SMS/OTP: Twilio/MSG91
Push Notifications: FCM
File Storage: AWS S3/Firebase Storage

Key Features Implementation

Separate Login Systems: Distinct authentication flows for users and vendors
Role-Based Access: Different interfaces and permissions
Real-time Updates: Live availability, booking status
Payment Integration: UPI, cards, wallets, subscriptions
Maps Integration: Location search, navigation, geocoding
Communication: In-app chat, calling, notifications
Rating System: Bidirectional feedback mechanism
Offline Support: Basic functionality without internet

Performance Optimizations

App load time: Under 3 seconds
Real-time map updates with smooth scrolling
Image compression and lazy loading
Offline data caching
Battery usage optimization
This comprehensive prompt ensures a complete separation between user and vendor experiences while maintaining Uber-like simplicity and user-friendliness throughout both interfaces.
