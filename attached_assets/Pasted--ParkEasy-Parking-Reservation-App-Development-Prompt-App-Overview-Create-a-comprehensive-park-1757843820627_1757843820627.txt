# ParkEasy - Parking Reservation App Development Prompt

## App Overview
Create a comprehensive parking reservation mobile app similar to Uber's design philosophy, focused on the Indian market with ₹ INR pricing and bilingual support (English/Hindi).

## Unified Login System Requirements

### 1. Single Registration Flow
- **Phone Number Authentication**: Primary login via mobile OTP
- **Role Selection Post-Login**: After successful authentication, users choose:
  - "I want to find parking" (User mode)
  - "I want to list my parking space" (Vendor mode)
  - "Both" (Switch between modes)
- **Profile Completion**:
  - Users: Name, vehicle details (optional RC upload)
  - Vendors: Business name, ID proof, address verification, bank/UPI details
  - Dual-role accounts: Complete both profiles

### 2. Dynamic Dashboard Based on Role
- **Role Switcher**: Top-right toggle button to switch between User/Vendor modes
- **Persistent Login**: Remember last used mode, but allow easy switching

## Technical Specifications

### Core Technology Stack
- **Frontend**: React Native (iOS + Android)
- **Backend**: Node.js/Django with MongoDB/PostgreSQL
- **Maps Integration**: Google Maps API
- **Payment Gateway**: Razorpay/Paytm
- **Real-time Updates**: WebSocket/Firebase
- **Push Notifications**: FCM
- **SMS/OTP**: Twilio/MSG91

### Key Integrations Required
1. **Google Maps API**: For location, navigation, and geocoding
2. **Payment Gateways**: UPI, cards, wallets
3. **SMS Service**: OTP verification
4. **Cloud Storage**: Photo uploads
5. **Analytics**: User behavior tracking
6. **Push Notifications**: Booking updates

### Performance Requirements
- **App Load Time**: Under 3 seconds
- **Map Rendering**: Real-time with smooth scrolling
- **Offline Mode**: Basic functionality when internet is poor
- **Multi-language**: Seamless English/Hindi switching
- **Accessibility**: Support for screen readers

## Monetization Model
- **Commission**: 20% from vendor earnings
- **Subscription Revenue**: Weekly/monthly/yearly passes
- **Premium Features**: Priority booking, cancellation protection
- **Advertisement**: Promoted parking spots for vendors

## Launch Strategy
1. **Phase 1**: Delhi NCR (Gurgaon, Noida, Delhi)
2. **Phase 2**: Mumbai, Bangalore, Pune
3. **Phase 3**: Tier-1 cities expansion
4. **Partnership**: Malls, offices, hospitals, airports
